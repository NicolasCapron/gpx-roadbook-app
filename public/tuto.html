1. Comment ça marche

Le fichier GPX exporté contient deux choses :

  • Le parcours (trace GPS originale)
  • Les waypoints (communes, ravitos, secteurs pavés, dangers…) ajoutés par le roadbook

Quand vous chargez ce fichier sur votre Garmin comme parcours, le GPS affiche le nom de chaque waypoint quand vous en approchez. Exactement comme un roadbook qui défile automatiquement.

💡 Astuce : Le nom affiché sur le Garmin est au format 🏘 Roubaix (-42.5km) — le kilométrage restant est intégré directement dans le nom pour un repérage facile.

2. Exporter le GPX enrichi

  1. Chargez votre fichier GPX dans l'application
  2. Cliquez sur ✨ Détecter les communes pour remplir le roadbook automatiquement
  3. Ajoutez vos points personnalisés si besoin (ravitos, pavés, dangers…)
  4. Cliquez sur ⬇ GPX pour télécharger le fichier enrichi

Le fichier exporté s'appelle votre-trace_roadbook.gpx.

3. Transférer sur le Garmin

Option A — Via Garmin Connect (recommandé)

  1. Allez sur connect.garmin.com → Entraînement → Parcours
  2. Cliquez Importer et sélectionnez votre fichier _roadbook.gpx
  3. Donnez un nom au parcours et cliquez Enregistrer
  4. Le parcours se synchronise automatiquement sur votre Garmin via Wi-Fi ou Bluetooth
⚠️ Attention : Garmin Connect peut parfois supprimer les waypoints à l'import. Vérifiez qu'ils apparaissent bien. Si ce n'est pas le cas, utilisez l'option B.

Option B — Via câble USB (le plus fiable)

  1. Branchez votre Garmin en USB à votre ordinateur
  2. Le Garmin apparaît comme un disque amovible
  3. Copiez le fichier _roadbook.gpx dans le dossier Garmin/NewFiles/
  4. Débranchez proprement — le Garmin importe automatiquement le fichier au redémarrage
💡 Astuce : Le dossier NewFiles est le plus fiable : le Garmin le traite à chaque démarrage et déplace le fichier dans le bon emplacement interne.

4. Configurer les alertes

Pour recevoir une alerte (bip + affichage du nom) à l'approche d'un waypoint, il faut activer les alertes de parcours sur votre Garmin :

  1. Sur le Garmin, allez dans Paramètres → Parcours (ou Navigation)
  2. Activez Alertes de parcours ou Course Point Alerts
  3. Lancez votre activité, puis chargez le parcours depuis le menu Navigation → Parcours

Selon votre modèle, le chemin peut varier :

Paramètre Emplacement typique
Alertes de parcours Paramètres → Activité → Navigation → Alertes de parcours
Guidage virage Paramètres → Activité → Navigation → Guidage
Écran parcours Paramètres → Activité → Écrans → Ajouter → Carte

5. Par appareil

⌚ Edge 530 / 830 / 1030+

Support complet. Écran Course Points = roadbook défilant. Voir le guide Edge 830

⌚ Edge 540 / 840 / 1040

Support complet avec écran amélioré. Mêmes étapes que la série précédente.

⌚ Forerunner 255 / 955 / 965

Support des parcours avec waypoints. Transfert via Garmin Connect recommandé.

⌚ Fénix 7 / Enduro 2 / Epix

Support complet. Les waypoints sont affichés sur la carte carto intégrée.

💡 Règle générale : Si votre Garmin peut charger un parcours (pas juste une trace), il supportera les waypoints et les alertes.

6. Questions fréquentes

Les waypoints ne s'affichent pas ?

Vérifiez que vous avez bien chargé le fichier comme parcours (et non comme simple trace GPX). Essayez le transfert USB dans Garmin/NewFiles/ si Garmin Connect les a supprimés.

Pas de bip sonore à l'approche ?

Allez dans Paramètres → Tonalités et vérifiez que les alertes sonores sont activées. Vérifiez aussi que les alertes de parcours sont bien activées dans les paramètres de navigation.

Trop de waypoints communes, l'écran est surchargé ?

Dans l'application, supprimez les communes peu pertinentes avant d'exporter. Gardez les entrées/sorties de villes importantes et les points stratégiques (ravitos, pavés, dangers).

Puis-je modifier les points après export ?

Oui, le fichier GPX est un simple fichier texte. Vous pouvez l'éditer dans un éditeur de texte ou le recharger dans l'application.

Combien de waypoints peut gérer un Garmin ?

La plupart des modèles récents supportent au moins 200 waypoints par parcours, largement suffisant pour un roadbook.
