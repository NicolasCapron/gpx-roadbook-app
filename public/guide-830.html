1. Ce que tu vas obtenir

Un écran dédié sur ton Edge 830 qui affiche la liste des prochains points du roadbook, avec le type, le nom et le kilométrage restant :

Course Points
#1 DEP Départ — Lille 0.0
#2 COM Seclin -172.3
#3 MON 45m D+ (4.2%) -168.1

#6 RAV Ravito Orchies -132.0
▲▼ scroll · le point actif suit ta position

L'écran défile automatiquement — le prochain waypoint est toujours en surbrillance. Exactement comme une bandelette qui avance.

2. Importer le parcours

Option A — USB (le plus fiable)

  1. Exporte le GPX enrichi depuis l'app (bouton ⬇ GPX)
  2. Branche le Edge 830 en USB
  3. Copie le fichier _roadbook.gpx dans Garmin/NewFiles/
  4. Débranche — le 830 importe le parcours au redémarrage

Option B — Garmin Connect

  1. Va sur connect.garmin.com → Entraînement → Parcours → Importer
  2. Upload le fichier _roadbook.gpx
  3. Synchronise le 830 via Wi-Fi ou Bluetooth
⚠️ Garmin Connect peut parfois ignorer les Course Points à l'import. Si les waypoints n'apparaissent pas, utilise l'USB.

3. Configurer l'écran Course Points

C'est l'étape clé — ajouter la page "Course Points" à tes écrans d'activité :

  1. Sur le Edge 830, va dans Menu → Paramètres → Profils d'activité et sélectionne ton profil (Route, VTT…)
  2. Va dans Écrans de données
  3. Descends jusqu'à Ajouter un écran et sélectionne-le
  4. Choisis Course Points (ou "Points de parcours")
  5. Place cet écran en 2e ou 3e position pour y accéder rapidement en swipant
💡 Astuce : Tu peux aussi ajouter un écran de données avec le champ "Prochain point de parcours" pour avoir juste le prochain waypoint affiché en gros sur un écran standard.

Champs de données recommandés

Sur tes autres écrans, ajoute ces champs liés au parcours :

Dist. prochain pt Distance jusqu'au prochain Course Point Nom prochain pt Nom du prochain waypoint (ex: #5 [PAV] Secteur de Mons) Dist. restante Kilomètres restants sur le parcours total Écart parcours Déviation par rapport au parcours prévu

4. Activer les alertes

  1. Menu → Paramètres → Profils d'activité → [ton profil]
  2. Va dans Navigation
  3. Active Alertes de parcours (Course Point Alerts)
  4. Optionnel : active Guidage virage pour les indications directionnelles
  5. Dans Tonalités, vérifie que les alertes sonores sont activées

Résultat : un bip + popup avec le nom complet du waypoint à l'approche :

PROCHAIN POINT
#5 [PAV]
Secteur de Mons
→ 350m

5. Naviguer avec le roadbook

  1. Lance ton activité (bouton ▶)
  2. Va dans Menu → Navigation → Parcours
  3. Sélectionne ton parcours roadbook et Démarrer
  4. Swipe vers l'écran Course Points — ton roadbook est là

Pendant l'activité

Swipe ←→ Naviguer entre tes écrans (carte, données, roadbook) Swipe ▲▼ Scroller dans la liste des Course Points Auto-scroll La liste suit ta position — le prochain point est toujours visible
💡 Combo idéal : Écran 1 = Carte avec parcours · Écran 2 = Course Points (roadbook) · Écran 3 = Données (vitesse, D+, distance)

6. Optimiser l'affichage

Trop de waypoints ?

Si ta liste est trop longue (beaucoup de communes), tu peux avant l'export :

  • Supprimer les communes peu importantes dans l'app (bouton ✕ dans le roadbook)
  • Garder uniquement les points stratégiques : montées, pavés, ravitos, dangers
  • Les communes d'entrée/sortie de zone urbaine

Noms trop longs ?

Le Edge 830 affiche environ 20 caractères par ligne. Les noms du GPX exporté sont déjà optimisés :

Affiché sur le GarminSignification
#3 [MON] 45m D+ (4.2%)Étape 3, montée de 45m à 4.2%
#7 [PAV] Mons-en-PévèleÉtape 7, secteur pavé
#9 [RAV] OrchiesÉtape 9, ravitaillement
#1 [DEP] Départ — LilleDépart depuis Lille

Raccourci écran unique

Si tu ne veux pas un écran dédié, ajoute le champ "Prochain point de parcours" sur un écran existant. Il affiche en permanence le nom et la distance du prochain waypoint — idéal en une ligne.
